- 强制故障转移 p50 15.41 ms（含 10ms 重试退避）；冷却稳态 p50 0.434 ms（与基线持平，冷却机制有效）

## 结论

- 网关单请求基线开销 p50 0.422 ms；启用全部 5 个内置插件后增加 +0.060 ms/请求。
- 流式 TTFT 开销：+0.278 ms。
- 故障转移：冷却稳态与基线持平；强制每次重试+切换的开销来自配置的退避时间（10ms），网关自身开销毫秒级。
- 精确缓存命中略快于转发路径；上游为真实大模型（秒级延迟）时收益为秒级。
- 语义缓存命中路径 p50 0.469 ms（含进程内 mock embed 步骤；真实部署需另加 embed 网络往返）。
- 并发 8→64 RPS 下降源于单进程 Python GIL 与事件循环争用；生产部署可用多 worker 横向扩展。
