## 决策记录（供晨间复核）

1. **Anthropic embeddings 不实现**（S1）：web 检索确认 2026-10 Anthropic 仍无一方 embeddings
   API（官方推荐 Voyage AI）。基类默认 UpstreamUnavailable → dispatcher 失败转移到
   embeddings 可用部署，正是设计语义。记录于 operations.md 边界 5。
2. **向量检索用暴力 cosine**（S3）：InMemory 直接遍历；Redis SCAN + 逐条 GET。蓝图风险表
   既定决策（先容量上限起步）；`max_entries`（默认 256）只约束进程内存储，Redis 命名空间
   靠 TTL 回收——规模边界写入 operations.md 边界 12。
3. **embed 走 dispatcher 而非完整插件链**（S3）：`GatewayApp._plugin_embed_fn` 用
   `state_dispatcher().execute_embedding` 复用路由/失败转移，但不过插件链——避免认证/日志
   递归与无关开销。失败一律返回 None → 插件直通。
4. **语义命中同时计入两个指标**（S3）：`ctx.cache_hit` 驱动的既有
   `gateway_cache_requests_total{result="hit"}` 照常累加，另有
   `gateway_semantic_cache_hits_total{model}` 区分来源。不改既有指标（兼容纪律）。
5. **命中计费口径**：语义命中与精确命中同样走 `ctx.cache_hit` → token 配额豁免路径自动一致
   （缓存命中不计费）。
6. **TTL/阈值保守值**：阈值 0.95（>0.99 时部分相似文本不命中，<0.9 误命中风险上升），
   TTL 600s 独立于精确缓存，容量 256。全部可配。
